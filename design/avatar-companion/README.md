- 作者与许可：pranav27，CC BY 4.0；页面保留简短署名，GLB 保留原始作者与许可元数据，展示适配说明保存在 `public/models/mercedes-g63-amg.LICENSE.txt`。
- 当前模型：`public/models/mercedes-g63-amg.glb`，直接使用作者的原始 GLB，10,315,296 字节（约 10.32 MB），SHA-256 为 `4fec52ebf5c009cdf8a867bb5d8bb24dbb8a4464223f9d6a40312ba8231034d7`。不再进行 Meshopt 压缩、顶点量化或网格简化，保留 54 个网格、187,887 个三角面及全部 17 种材质；原始文件不包含图片贴图。
- 网页适配：`src/lib/avatar/imported-car.ts`；加载与交互：`src/scripts/avatar-scene.ts`。
- 交互：拖动或左右方向键旋转、切换车灯、复位视角、旋转一周。作者模型没有动画，左右车门合并在网格中，因此不提供开门功能。
- 重新准备模型：`npm run build:avatar-model -- <已授权原始GLB的本地路径>`，先核对原始下载的 SHA-256，再逐字节复制到发布目录，不修改 GLB 元数据。无参数时核对已发布的原始文件并更新独立署名说明；当前工作机仍保留 `.astro/model-sources/pranav27-g63.original.glb` 下载缓存。
- 网页保留作者的车漆、玻璃、轮毂和橡胶材质。车灯交互使用独立复制的灯具材质，联动灯面的明暗、发光和尾灯透明度；前灯光圈与柔和光晕按原始灯具顶点定位并随车身旋转。下载的原始 GLB 不写入这些展示效果。放大页像素比上限为 2、阴影图为 1024；首页保留较低的绘制开销。加载与下载使用原始版本标记，避免浏览器沿用此前的压缩文件。
- 网页按需渲染，模型静止或离开视口时停止重绘；关闭动态时仍可直接切换车灯、复位和调整观察角度。
- `/companion/` 使用单一大展台，桌面最大宽度 1480px，高度随视口适配；只保留小号名称、返回与下载入口、底部控制和简短署名。已移除侧边长文案、配色装饰、展示页气泡和页脚装饰。手机收紧展台的垂直留白，控制按钮高度至少 44px；独立展示页使用更紧凑的安全视野，仍为完整旋转保留边界。
- 刷新与加载阶段使用文字和轻量圆环提示，已移除简化车模插画。文件下载后继续等待场景与着色器准备，完成首帧渲染后再淡入真实模型；失败时提供重新加载入口。加载状态保留展示区和操作区的尺寸，手机与桌面布局均不随状态切换跳动，减少动态设置会停用圆环和淡入。

原几何版位于 `src/lib/avatar/g-class.js`，保留作历史参考，网页不再导入。以下保留更早的小渡机器人的设计记录，便于回看。

## 小渡 · 月湾的小信使（历史版本）

本轮根据用户的补充要求，改为自由设计、有生命感的博客角色。小渡是穿绿色短披肩、带着笔记本的小信使机器人，已替换首页第一版人物，并新增 `/companion/` 放大互动页。

具体调研来源、设计取舍与视觉规格见 [RESEARCH.md](RESEARCH.md)。

## 使用与交付

- 首页：点击小渡或「打个招呼」挥手；「翻翻笔记」抬起笔记本；「转个身」查看侧面和背面。
- 放大预览：进入 `/companion/`，或点击首页的「小渡 · 月湾的小信使」。
- 独立模型：`public/models/xiaodu-companion.glb`，约 2 MB，包含 5 段动画。
- 模型源文件：`src/lib/avatar/character.js`。
- 组件与控制：`src/components/AvatarCompanion.astro`、`src/scripts/avatar.ts`、`src/scripts/avatar-scene.ts`。
- 展示页面：`src/pages/companion.astro`、`src/styles/companion-page.css`。
- 设计预览：`xiaodu-design-preview.jpg`。
- 手机设计页：`xiaodu-mobile-full.jpg`。

修改模型后执行 `npm run build:avatar-model`，更新独立 GLB。网页直接使用模型源文件，下载 GLB 是独立操作，不会为了展示人物而重复加载 GLB。

没有新增运行依赖。外部案例只作为设计方法参考，当前展示使用项目自行构建的几何和材质。
