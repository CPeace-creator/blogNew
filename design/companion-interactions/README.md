# 车模与小汐交互改进

日期：2026-11-27。

## 使用方式

- 首页点击大 G 车身，页面带到月湾书屋，车辆驶入并停靠；小汐配合出发和到达作出回应。移除独立的出发文字按钮与首页操作说明，车灯、复位、旋转控制继续可用。
- 车身通过实际模型命中判断，点击画布空白处、旋转拖动或取消手势均不出发。车身悬停显示可点击光标与轻微光环。键盘可触发出发并旋转车模。
- 摸头得到笑脸，五秒内连续三次独立摸头有爱心回应；戳脸轮换眨眼、害羞、爱心；尾巴触发水花，身体或桌面作出好奇回应。
- 双击角色播放上游原生自拍动作；这里是模型动作，不调用设备摄像头。
- 右键、长按、菜单键或 Shift+F10 打开菜单。八个动作入口为比耶、害羞、星星眼、眨眼、自拍、泡泡、水花和恢复乖巧。
- 拖动角色后吸附两侧并回应新位置；Home 复位。菜单关闭后恢复可见控件的焦点。
- 快速连续选择原生动作时保留最后一次选择。收起或隐藏标签页时重置当前动作，未完成的点击、长按手势不会稍后误触。
