# 月湾音乐与到访联动

2026-11-27，根据本次对话完成三项改动。

- BGM：用户最初指定 Zxxy、叶子舒的氛围版；汽水链接仅开放约 30 秒试听。用户随后允许使用任意可下载版本，因此接入完整的伦桑翻唱版，时长 245.2045 秒，文件 3,924,141 字节。曲目、歌手和来源与实际音频一致。
- 来访：上方车模入口触发同页书屋的车辆驶入、树旁停靠、落樱与角色回应。车辆沿预设路线向前行驶，日夜状态与车模、角色保持同步。再次进入首页可恢复停靠状态。
- 角色：原创蓝白矢量看板娘小汐，分层动画实现眨眼、视线、呼吸、头发、挥手、音乐回应和阅读持书。支持拖动吸附、方向键移动、Home 复位、快捷菜单、随机文章和收起。此版本不使用第三方 Live2D 模型。
