# 月湾书屋 · 可移动内容窗

2026 年 11 月 25 日，根据用户反馈完成。

## 交互

- 点击电脑、桥梁、书架、抽屉、樱花树、信封或下方栏目，在当前页面打开对应内容。
- 桌面默认从右侧打开浮动内容窗；拖动标题栏移动，拖动右下角改变大小。窗口限制在可视范围内。
- 放大与缩小按钮改变窗口尺寸；最大化使用整页可视区域，还原后回到之前的位置和大小。
- 最小化后收进右下角的「接着读」，保留当前内容和阅读位置；恢复后可以继续阅读。
- 在内容窗中打开本站其他文章时继续使用同一窗口，返回按钮回到本次阅读路径中的上一页并恢复滚动位置。
- 关闭按钮和 Esc 返回书屋入口。文章图片查看器打开时，第一次 Esc 优先关闭图片，内容窗继续保留。
- 手机使用底部抽屉。标题栏可以向上、向下拖动来改变高度，并保留放大、缩小、最大化、收起和恢复。
- 书架在内容窗中使用紧凑的文字目录，打开文章后展示完整图文。

六个入口仍保留原始链接，脚本不可用时可以访问独立页面。内容窗复用现有文章、目录、个人介绍和 BIM 实验室，保留图片查看器及演示交互。嵌入时隐藏重复导航、侧栏与页脚。

首页和小渡展示页的独立人物暂停按钮已移除；全局动态偏好和系统减少动态设置仍生效。

## 兼容处理

同一页面在个人介绍与联系方式之间切换时，直接复用文档并滚动到目标章节，不等待不存在的新页面加载事件。

含三维画布、内容窗或嵌入文档的页面采用直接主题切换，避免把实时画布与嵌入页面捕获成整页过渡纹理。浏览器中已复查两轮深浅切换，内容窗同步主题且无控制台错误。

- 新增 5 项窗口几何测试：移动边界、缩放下限、居中缩放、手机底边约束、小屏恢复。
- 浏览器检查六个入口，书屋主地址保持不变；验证窗内文章导航和返回、关于我与联系方式之间的切换。

- 验证图片查看器与 Esc 优先级、窗口放大缩小、最大化还原、最小化恢复、键盘操作、鼠标拖动与调整大小。
- 验证手机 390 × 844 尺寸，抽屉不横向溢出，标题栏可改变高度。
