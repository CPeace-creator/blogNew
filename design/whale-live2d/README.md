## 网站适配

使用本地 Cubism Core、PIXI.js 与 pixi-live2d-display 渲染，保留物理效果与源动作。博客适配驱动眨眼、视线、笑脸和比耶；菜单可播放上游吹泡泡动作。动作结束后恢复默认参数快照。

模型基于透明像素范围适配画布，桌面按 24 帧上限更新。手机默认收起，展开时才载入运行时和模型。收起、对话框遮挡、后台和减少动态时停止连续绘制。加载失败可重试。

继续使用原有拖动、边缘吸附、方向键移动、Home 复位、音乐控制、随机文章和书屋链接。菜单优先放在角色上方，并在拖动后限制到屏幕范围内，避免盖住菜单开关。持久节点使用独立版本标识，避免部署后沿用旧版矢量角色。
